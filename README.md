# Reproducible infectious-disease reports

This repository contains the infectious-disease report and presentation produced for [OpSciHack 2026](https://www.openinnovationlifesciences.com/opscihack), the open-science hackathon held in Zurich on 3–4 October 2026. The event is also listed publicly by [ReproHack](https://www.reprohack.org/event/37/) and [Luma](https://luma.com/p7i9glwg).

The report and presentation files were modified during the event. The latest public version is archived on [Zenodo](https://zenodo.org/records/23338514).

## Repository contents

- `Report_OpSciHack2026_04102026.docx` — report prepared during OpSciHack 2026.
- `Pitch_OpSciHack2026_04102026.pptx` — presentation prepared during OpSciHack 2026.
- `LICENSE` — repository license.
- `README.md` — this project description.

The report and presentation are the current deliverables in this repository.
