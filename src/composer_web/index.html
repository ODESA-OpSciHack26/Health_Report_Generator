Data used

Publisher: Federal Office of Public Health, FOPH/BAG · Source: Infectious Diseases Dashboard, IDD

Geographic context: Switzerland and Liechtenstein where the saved bundle supports it

Health reports use saved data from the publisher's Infectious Diseases Dashboard (IDD), obtained through the publisher's API as recorded by the existing acquisition and provenance records. The publisher states that its API data are updated weekly on Wednesdays; individual disease series may follow different publication schedules. This workspace renders a retained snapshot and does not automatically refresh when the source website changes.
