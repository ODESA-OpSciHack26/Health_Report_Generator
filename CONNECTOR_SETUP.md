# Retired GitHub-backed interface

The GitHub-backed Marimo interface and its artifact-download and repository
configuration adapters are retired from this product tree. Earlier
implementations remain in Git history.

Use the [local composer](docs/composer.md) for supported browser workflows.
It has a local access credential and does not require a GitHub token.

The selected-report renderer and GitHub workflow remain available separately.
Retiring the interface does not establish new runtime acceptance of that route.

The legacy optional UI Dockerfile and dependency locks are also retired.
Use the report environment documented in [setup](GETTING_STARTED.md).
