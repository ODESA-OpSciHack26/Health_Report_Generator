# Retired local reporting form

The host-local Marimo form and its adapter are retired from this product tree.
Their earlier implementations remain in Git history.

Use the [experimental local composer](composer.md) for supported browser
workflows. Its setup, supported inputs and interaction model differ from the
former form; this is not a claim of identical feature coverage.

The custom-report CLI and content-addressed cache remain available. See the
[main README](../README.md#custom-reports) for the retained command and its
output-replacement warning.

The [GitHub-backed interface](../CONNECTOR_SETUP.md) is also retired.
The composer is not required to run the canonical three-audience
reporting pipeline.
